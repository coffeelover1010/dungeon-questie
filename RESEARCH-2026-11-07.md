# Dungeon Questie review — 7 November 2026

Version 0.1.6 contains 266 unique quests across 25 populated dungeon groups,
63 curated pickup pins and 467 walkthrough nodes. Four groups have no records:
Krol'dok Stronghold, Alcaz Prison, Blackmaw Hold and The Shaper's Terrace.
Evidence totals: 126 beta-cache records, five Forever database records and
135 Classic references. Field-level confirmations do not change the evidence
classification of unrelated fields in the same quest.

## Dependency recommendation

Prefer optional QuestieDB support for a future shared-data integration. Its
`src/api.lua` explicitly supports independent consumers, named field reads,
flavor selection and a compatible contract-version range. Questie's `Public/`
API supports readiness and tracking events; its internal database module is
not the appropriate stable integration surface for this purpose.

A required dependency would prevent the checklist loading without the provider.
An optional provider with curated fallback keeps the checklist available and
allows Forever-specific overrides and known gameplay exceptions to win. Merely
adding OptionalDeps does not synchronize anything: a real integration needs
contract/flavor checks, missing-data handling and resolver tests. No runtime
dependency or automatic overwrite behavior was added in this review.

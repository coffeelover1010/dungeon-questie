# Missing quest follow-ups — 1 November 2026

Added six catalogue records: Gnome Improvement (2948), Nogg's Ring Redo
(2950), Final Passage (1394), The Test of Righteousness reward step (1806),
The Corruption Abroad (3765), and The Greenwarden (463). The generated
catalogue now has 263 unique quests. Test of Lore (6628) is also included
as an intermediate walkthrough node before Final Passage.

DungeonJournal 1.6.5 was used to identify gaps, not as a build input:
https://www.curseforge.com/wow/addons/dungeonjournal/files/9259740

The additions use independently read factual fields from the existing pinned
CMaNGOS Classic-DB snapshot, with original concise directions:
https://github.com/cmangos/classic-db/tree/ec4f596146be6467ea93c57397858e329e2db852

The downloaded snapshot SHA-256 matches the existing provenance record.
Only the six requested quest IDs plus 6628 extend the quest source subset;
unrelated newly available Classic prerequisite records were not adopted.
The input is data/reference-additions.json, applied before catalogue overrides.
These additions retain Classic reference labels, rather than claiming fresh
Forever gameplay verification. Pickup coordinates were not guessed.

Ring upgrades follow 2947/2949, the paladin reward follows collection step
1654, and Final Passage follows 6628, which follows the Library step 1160.
Faction and paladin race/class restrictions come from the licensed source.
The Corruption Abroad and The Greenwarden remain optional breadcrumbs;
neither is a hard gate on Researching the Corruption or Tramping Paws.
The existing player observation that Tramping Paws can be offered directly
is preserved. The Alliance ring beta-cache reference to unidentified quest
80131 is retained alongside the Classic 2948 follow-up, rather than erased.

Offline validation: Lua 5.1 and mocked UI checks, walkthrough graph closure,
cycle detection, progression and restriction checks, targeted follow-up and
optional-breadcrumb regressions, and deterministic source rebuild checks.
Installation backs up the previous runtime and verifies copied file hashes.
Live /reload, rendering, quest offers, rewards and turn-ins remain untested.
